# docs/archive/

Finished plans and point-in-time audits. Their work is done and no current
system doc depends on them; they are kept for history only. If you are looking
for how the product works today, read the docs one level up — start with
[`../README.md`](../README.md).

Nothing in here is read by a script or by `CLAUDE.md`. Internal links inside
these files may point at paths that have since moved; that's expected for frozen
history and is not worth fixing.
